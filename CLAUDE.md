# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Structure

Go monorepo that collects N CLIs, one per top-level subdirectory
(`changedetection-pp-cli/`, `fritzbox-pp-cli/`). Each CLI is an independent
subproject with its own `go.mod` and `Makefile`. Run commands **from inside the
CLI's directory**, not from the repo root. Add a new CLI as a sibling
subdirectory.

## Critical gotcha: generated code

Every CLI here is **generated** by the CLI Printing Press
(github.com/mvanhorn/cli-printing-press). Before editing one, read its own
`AGENTS.md`: fixes belong upstream or must be recorded in
`.printing-press-patches/`, otherwise a reprint overwrites them. Do not hand-bump
version/changelog files.

Files carrying a `Generated by CLI Printing Press` header are regenerated
wholesale. Extensions belong in their own files beside the generated ones —
`fritzbox-pp-cli` keeps its hand-written code in `internal/fritzbox/`,
`internal/cli/fritzbox_*.go`, `internal/store/fritzbox_*.go` and
`internal/config/fritzbox_config.go` for exactly this reason.

## Commands (from inside the CLI's directory)

- `make build` — build into `bin/`
- `make test` — `go test ./...`
- `make lint` — `golangci-lint run`
- `make install`
- single test: `go test ./internal/cli -run TestName`
- MCP server: `make build-mcp` / `make install-mcp`

## Env / config

Secrets live in each CLI's `config.toml` (gitignored; only
`config.toml.example` is committed). Env vars override the config file.

**changedetection-pp-cli**
- `CHANGEDETECTION_API_KEY`
- `CHANGEDETECTION_BASE_URL` — must include `/api/v1`
- `CHANGEDETECTION_CONFIG` — config path
- `CHANGEDETECTION_HOME` — relocate cache/DB/state

**fritzbox-pp-cli** — talks to an AVM router on the local network. TR-064 must
be enabled on the box first (Home Network > Network > Network Settings > Allow
access for applications).
- `FRITZBOX_PASSWORD` — required; `FRITZBOX_USERNAME` only if the box has more
  than one user
- `FRITZBOX_ADDRESS` — router origin, defaults to `http://fritz.box`; never
  include the TR-064 port, the CLI switches to 49000 on its own
- `FRITZBOX_SID` — session id; normally left unset and minted by `auth login`
- `FRITZBOX_CONFIG` — config path
- `FRITZBOX_HOME` — relocate cache/DB/state

`fritzbox-pp-cli snapshot` is what populates local history; `hosts diff`,
`wan history` and `log search` read it and need at least two snapshots to
report anything.

## `--agent` flag

On any command, forces non-interactive JSON output. Structured exit codes:
`0` ok, `2` usage, `3` not found, `4` auth, `5` API, `7` rate-limit, `10` config.
