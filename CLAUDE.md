# CLAUDE.md

Go monorepo of independent CLIs, one per top-level directory, each with its own
`go.mod` and `Makefile`. Run `make` and `go` from inside the CLI's directory:
the repo root has no module. A new CLI is a new sibling directory.

## Generated code

Every CLI is printed by CLI Printing Press
(github.com/mvanhorn/cli-printing-press), and a reprint overwrites the whole
tree. Before editing a CLI, read its `AGENTS.md`: it says when a fix belongs
upstream and how to record a local one in `.printing-press-patches/` so it
survives the reprint.

Files with a `Generated by CLI Printing Press` header are regenerated wholesale.
Hand-written code goes in its own files beside them, named after the CLI —
`fritzbox-pp-cli` keeps its own in `internal/fritzbox/`,
`internal/cli/fritzbox_*.go`, `internal/store/fritzbox_*.go` and
`internal/config/fritzbox_config.go`.

## Credentials

Each CLI keeps its credentials in its own directory, in gitignored
`config.toml` and `.env`; the committed templates (`config.toml.example`,
`.env.template`) list the variables and their gotchas. Env vars override the
config file. The CLIs read the environment, not `.env`, so load it first:
`set -a; . ./.env; set +a` (lines must be `KEY=value`).
